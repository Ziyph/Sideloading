# Ziyph's Sideloading Source

My [AltStore](https://altstore.io/)-style source for apps without one.

## Installation

Visit [this AltDirect page](https://altdirect.app/?url=https://raw.githubusercontent.com/Ziyph/Sideloading/main/source.json) to add this source to whichever sideloading solution you wish.
